📖 Quick lesson: Strings

A string is a sequence of characters. Python uses quotes to mark text. Characters have positions called indices, starting at 0.

Indexing and slicing

word = "banana"
print(word[0])   # b
print(word[-1])  # a
print(word[1:4]) # ana
print(word[::-1])# ananab

Changing text safely

name = "Rambod"
# name[0] = "H"  # Error!
new_name = "H" + name[1:]
print(new_name)  # Hambod
print(f"Hello, {name}!")

Remember: strings are immutable. You cannot replace one character in the original string. Create a new string instead.
