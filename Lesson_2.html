🧠 Lesson 2: Variables and User Input

A variable is like a labelled box that stores a value. The input() function asks the user a question and gives back text.

Try this new program (different from Lesson 1):

name = input("What is your name? ")

age = int(input("How old are you? "))


print("Hello,", name)

print("Next year you will be", age + 1)

Notice: name stores text, while age is converted to a number using int(). Type a whole number when asked for your age.
